# Автоматическая отправка заявок в WhatsApp

Приложение `cyprusguide.html` умеет работать в двух режимах.

| Режим | Что делает клиент | Что нужно |
|---|---|---|
| **По умолчанию** (`CONFIG.leadEndpoint` пустой) | Жмёт кнопку → открывается WhatsApp с готовым текстом → жмёт «Отправить» | ничего |
| **Автоматический** (`CONFIG.leadEndpoint` заполнен) | Жмёт кнопку — и всё. Сообщение приходит менеджеру само | этот обработчик + токен провайдера |

Полностью автоматически из браузера отправить нельзя: WhatsApp принимает
сообщения только от аккаунта, подтверждённого токеном. Токен нельзя класть
в HTML — его увидит любой посетитель. Поэтому нужен маленький серверный
обработчик: страница шлёт заявку ему, он шлёт её в WhatsApp.

## Быстрый старт на Vercel

1. Скопируйте `server/lead.js` в проект как `api/lead.js`.
2. Задайте переменные окружения (Project → Settings → Environment Variables).
3. Задеплойте и впишите адрес в `cyprusguide.html`:

```js
const CONFIG = {
  leadEndpoint: 'https://ваш-проект.vercel.app/api/lead',
  ...
};
```

## Переменные окружения

Общие:

```
MANAGER_WHATSAPP=996500054367     # куда приходят заявки, только цифры
ALLOWED_ORIGIN=https://ваш-сайт   # откуда разрешён вызов (по умолчанию *)
WA_PROVIDER=meta                  # meta | twilio | telegram
```

### Вариант 1 — WhatsApp Cloud API (Meta), `WA_PROVIDER=meta`

```
META_PHONE_NUMBER_ID=...
META_TOKEN=...
```

Где взять: developers.facebook.com → создать приложение → продукт WhatsApp →
раздел API Setup. Там же выдаётся тестовый номер и постоянный токен.

Важное ограничение Meta: **бизнес пишет первым только шаблонным сообщением.**
Свободный текст уходит, если получатель писал вам в последние 24 часа.
На практике проще всего один раз написать боту с номера менеджера — окно
откроется, и заявки будут приходить обычным текстом. Для стабильной работы
согласуйте шаблон в Business Manager и отправляйте `type: 'template'`.

### Вариант 2 — Twilio, `WA_PROVIDER=twilio`

```
TWILIO_ACCOUNT_SID=...
TWILIO_AUTH_TOKEN=...
TWILIO_WHATSAPP_FROM=whatsapp:+14155238886
```

Заводится за 10 минут в песочнице Twilio, менеджер один раз отправляет
join-код боту. Дальше заявки приходят автоматически.

### Вариант 3 — Telegram, `WA_PROVIDER=telegram`

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Самый быстрый путь: бот создаётся у @BotFather за минуту, без модерации и
ограничений на 24-часовое окно. Если WhatsApp нужен именно как канал для
клиента, а вам достаточно получать уведомление о заявке — этот вариант
надёжнее всех.

## Проверка

```bash
curl -X POST https://ваш-проект.vercel.app/api/lead \
  -H 'Content-Type: application/json' \
  -d '{"name":"Тест","phone":"+996700123456","city":"Пафос","people":"2"}'
```

Ответ `{"ok":true}` — заявка ушла. Ошибки пишутся в логи функции.

## Если отправка не удалась

Приложение это обрабатывает: показывает предупреждение и открывает WhatsApp
с готовым текстом, чтобы заявка не потерялась. Плюс каждая заявка
сохраняется в `localStorage` браузера под ключом `cy_leads`.
