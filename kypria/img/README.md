# Фотографии для сайта KYPRIA

Положите сюда свои снимки — страница подхватит их без правок кода,
если названия совпадут:

| Файл | Где появится |
|---|---|
| `hero-coast.jpg` | Экран ноутбука в первом блоке |
| `limassol.jpg` | Карточка «Лимассол» |
| `paphos.jpg` | Карточка «Пафос» |
| `nissi.jpg` | Карточка «Нисси-бич и Мыс Греко» |
| `troodos.jpg` | Карточка «Горы и Киккос» |
| `larnaca.jpg` | Карточка «Соляное озеро» |
| `nicosia.jpg` | Карточка «Никосия» |

Требования: JPG, длинная сторона 1600–2000 px, вес до 400 КБ.
Горизонтальные кадры — кроме «Пафоса», он вертикальный.

Пока файлов нет, подставлены снимки Кипра с Unsplash; если и они не
загрузились, остаётся градиентная подложка — пустых блоков не бывает.
