# Kipr

Лендинг alfa — консалтинг по обучению на Кипре, и старый сайт студии.

## Что где

- `index.html` — лендинг alfa. Один файл: разметка, стили и скрипты внутри.
- `studio/` — прежний сайт веб-студии из пяти экранов (`index.html`, `styles.css`, `script.js`).

## Как открыть

Локально: скачать `index.html` и открыть в браузере — всё работает без сервера.

## Публичная ссылка (GitHub Pages)

Чтобы сайт открывался у всех по ссылке с телефона:

1. Settings → Pages в этом репозитории.
2. Source: `Deploy from a branch`.
3. Branch: `claude/cyprus-slide-ghoqxg` (или смёржить ветку в `main` и выбрать его), папка `/ (root)`.
4. Save. Через пару минут адрес: `https://<владелец>.github.io/Kipr/`.

Для приватного репозитория Pages доступны только на платных планах — тогда
сделайте репозиторий публичным или разместите `index.html` на любом хостинге
статики (Netlify Drop, Vercel, Cloudflare Pages): достаточно перетащить файл.

## Что заполнить перед публикацией

Все суммы, сроки, названия вузов и почта отмечены в вёрстке как
`[ЗАПОЛНИТЬ: ...]` и подсвечены оранжевым пунктиром — их видно на странице.
Фотографии подключены с Unsplash по тематическим ссылкам; под каждой стоит
комментарий `[ЗАПОЛНИТЬ: заменить на своё фото]`. Если фото не загрузилось,
на его месте остаётся нарисованная сцена, а не пустой блок.
