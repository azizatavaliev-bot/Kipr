# Kipr
кипр приложение 

## Хиро-слайд

`index.html` + `styles.css` — первый экран тревел-лендинга: плоский оранжевый фон,
крупный serif-заголовок «Кипр», pill-навигация, SVG-иллюстрация лагуны поверх букв,
стеклянная карточка с CTA. Без внешних ассетов — открывается двойным кликом.

Палитра и CTA правятся в блоке `:root` файла `styles.css`.
